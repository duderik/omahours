# Changelog

## 1.0.0 (unreleased)

First version: bar widget with project list, start and pause, inline editing with time input (`2h22m`, `+2h22m`, `-90m`, `0`), delete with confirmation, keyboard control, automatic pause on lock and suspend, heartbeat for power loss, configurable data file, read-only protection for unreadable data files. The data file uses the keys `version`, `last` and `projects` (`name`, `ms`, `since`); a file with any other field is opened read-only.
